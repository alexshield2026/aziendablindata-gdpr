# 🛡️ AZIENDA BLINDATA — GDPR & Cyber Risk Assessment Tool

Un'applicazione web leggera e professionale sviluppata in **Next.js 14**, **Tailwind CSS** e **TypeScript** per consentire agli imprenditori di valutare in 2 minuti il livello di rischio sanzionatorio GDPR e le vulnerabilità informatiche della propria azienda.

## 🚀 Come installare ed eseguire in locale

1. **Estrarre il file ZIP** ed entrare nella cartella del progetto:
   ```bash
   cd aziendablindata-gdpr-assessment
   ```

2. **Installare le dipendenze:**
   ```bash
   npm install
   ```

3. **Avviare il server di sviluppo:**
   ```bash
   npm run dev
   ```

4. Aprire `http://localhost:3000` nel browser.

## ☁️ Distribuzione su Vercel (Gratis)

1. Crea un repository su **GitHub** chiamato `aziendablindata-gdpr-assessment`.
2. Carica i file del progetto sul repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - GDPR Risk Assessment Tool"
   git branch -M main
   git remote add origin https://github.com/TUO_UTENTE/aziendablindata-gdpr-assessment.git
   git push -u origin main
   ```
3. Vai su **[Vercel.com](https://vercel.com)** e clicca su **"Add New Project"**.
4. Importa il repository GitHub appena creato e clicca su **"Deploy"**.
5. In pochi secondi il tuo tool sarà online con un link tipo:
   `https://aziendablindata-gdpr.vercel.app`
